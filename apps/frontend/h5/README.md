# h5/ — 手机 H5 业务内核

面向手机的 H5 应用，是**所有壳工程最终加载的业务载体**。

## 状态

**占位目录，暂无实现。** 仅保留本 README 标记约定位置。

## 职责边界

- 承载博客面向读者的核心业务（文章列表、详情、分类、搜索等）。
- 同时服务两类访问：手机浏览器直接访问，以及各端壳工程（微信小程序 / 飞书 / 钉钉 / Android / iOS）通过 Webview 加载。
- 因为要被 Webview 加载，实现时必须考虑：
  - 页面需适配 Webview 容器（URL 参数注入登录态、容器标题栏、安全区域）；
  - 不依赖浏览器专属能力（如普通 Cookie 跨域），认证走约定好的 token 传递机制；
  - 平台差异能力（登录、分享、推送、支付）通过桥接层调用，由壳工程提供，业务代码不直接耦合任一平台 SDK。
- 与 `web/` 是两套独立应用，本目录不是 `web/` 的移动端样式变体。

## 关键约定

壳工程只做容器，**不在壳里重写业务**。任何业务逻辑都应落到本目录，这样一次修改对所有端生效。桥接接口的定义放 `shared/`。

## 何时填代码

满足以下条件才在本目录创建工程：

1. `specs/changes/` 中有对应的已批准变更记录；
2. `docs/frontend-backend-contract.md` 中所需端点不再标记 `【待办】`；
3. 桥接层协议（`shared/`）已定义并经 ADR 固化。

在此之前，本目录保持只有 README 的状态。
