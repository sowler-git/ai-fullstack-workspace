# web/ — 桌面 Web 站点

面向公众的桌面浏览器访问站点。

## 状态

**占位目录，暂无实现。** 仅保留本 README 标记约定位置。

## 职责边界

- 服务桌面浏览器访客，展示博客文章、分类、标签等公开内容。
- 与 `h5/` 是**两套独立应用**，不是同一份代码的响应式适配（这是项目约定，见上层 README）。
- 数据全部来自后端契约，不得内嵌业务 mock 作为最终实现。
- 不承载后台管理功能，那是 `admin/` 的职责。

## 何时填代码

满足以下条件才在本目录创建工程：

1. `specs/changes/` 中有对应的已批准变更记录；
2. `docs/frontend-backend-contract.md` 中所需端点不再标记 `【待办】`；
3. 已明确构建工具与框架选型，并写入 ADR（`docs/adr/`）。

在此之前，本目录保持只有 README 的状态。
