# Backend — Spring Cloud

Imported from `spring-cloud-base` without source changes. This is a Maven reactor rooted at `pom.xml`; the original usage notes are in `SOURCE-README.md`.

Current baseline: JDK 8, Spring Boot 2.3.2.RELEASE, Spring Cloud Hoxton.SR9, Spring Cloud Alibaba 2.2.6.RELEASE, with user, order, gateway, interface, framework, common, tracing, picture, and SMS modules.

Keep deployable-service changes traceable to `specs/` and put cross-service contract tests in `../../tests/contract/`.
