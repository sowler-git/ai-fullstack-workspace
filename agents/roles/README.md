# Specialist Roles

- `product-spec`: clarifies outcomes and acceptance criteria.
- `backend`: owns Spring Cloud service and API implementation.
- `frontend`: owns React UI, accessibility, and client integration.
- `architecture`: evaluates cross-service and platform decisions.
- `quality`: plans automated tests and checks evidence.
- `security`: reviews authentication, authorization, data handling, and supply-chain risk.
- `release`: evaluates migration, observability, rollback, and deployment notes.

Create a role charter only when the role is introduced into an approved workflow.
